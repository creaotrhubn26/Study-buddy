# Analysis Reporting illustrations

Both illustrations were generated with the built-in OpenAI imagegen tool on 9 November 2026 for Study Buddy. They are educational illustrations, not Noroff screenshots or evidence of measured business performance. No official task solution was used. The original generated PNG bytes are preserved in this folder.

- `lesson-1-1-report-structure.png`: An evidence-based report. Four core report parts, with recommendations distinguished from conclusions.
- `task-1-1-question-funnel.png`: From broad questions to specific evidence. Organic social-media report planning for the handmade-candle scenario.

The final prompt set is stored in `imagegen-prompts.json` in the same order. Text explanations and captions in the app provide an accessible equivalent of each visual.
