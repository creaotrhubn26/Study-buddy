# ARP Task 2.3 — seven-step infographic guide

Original task: https://learning.noroff.no/mod/book/view.php?id=22937&chapterid=81735

Checked 2026-11-09. Original Study Buddy guidance, not an official solution.

## Task boundary

Task 2.3 requires a dataset of the learner's choice from Kaggle, loaded into MS Excel for basic Exploratory Data Analysis (EDA), followed by an original infographic built in GIMP. Inspect the data structure, variables and patterns; use appropriate visualisations and identify supported observations. The brief offers histograms, scatter plots and bar charts as examples, not a requirement to include all three. Choose suitable canvas dimensions: 800 × 1200 px is an example, not a fixed requirement; A4 belongs to the lesson demonstration. Save the editable GIMP project as .xcf and export the final infographic as JPEG .jpg. Cite external resources and keep the design original. No dataset, numerical findings, statistical significance or completed EDA is supplied by Study Buddy. Do not invent them or substitute another task's data. The brief specifies no word count, fixed number of charts, mandatory Word report, PowerPoint, 500-word essay or citation style. Data and image sources need traceable attribution and reuse checks; a public Kaggle listing does not by itself grant every reuse right. Correlation does not establish causation, and missing values are not automatically zeros. The optional .ora download is a six-layer OpenRaster layout guide with raster placeholder text, not native editable GIMP text, a completed .xcf or a final .jpg. Hide or replace guide layers, add actual charts and GIMP text layers, save .xcf and export .jpg. Its archive, layer images and preview were checked; opening in GIMP was not tested on this machine. The imagegen pictures are study aids, not evidence of learner EDA or a substitute for building the assigned GIMP project. Exam Resolver reviews the selected step and written evidence in English; it cannot certify unseen Excel calculations, GIMP layers or exports from notes. The learner inspects the actual files and submits them themselves.

## 1. Choose and document a Kaggle dataset

Browse Kaggle and choose a dataset that interests you and can answer a focused question. Record creator, title, dataset URL, version/update date, original source if linked, licence or reuse terms, and the files selected. Define the audience and one provisional question. Check that the data are available and suitable before designing a headline.

Check: No dataset is preselected. Public availability is not proof of unlimited reuse rights, and a proposed question is not a finding.

## 2. Import and profile the data in Excel

Download the chosen data and load it into MS Excel. Keep an original copy. Record rows, columns, what one row represents, variable types, units and any time/geographic scope. Check delimiters, decimal separators, date interpretation, missing values and potential duplicates. Log cleaning or filters and their reasons before analysing the data.

Check: Keep missing values separate from genuine zeros. Do not delete unusual observations or duplicate-looking rows without checking the data definition.

## 3. Explore, calculate and verify the evidence

Use appropriate summaries and charts for your question: category counts or totals with a bar chart, a numerical distribution with a histogram, or two numerical variables with a scatter plot. Record the actual worksheet/range, formula or summary method, denominator, filters, sample size, chart file and observed result. Reconcile selected numbers against the source and note uncertainty or data-quality limits.

Check: The brief does not require every example chart or a statistical test. A correlation is not evidence that one variable caused another. Leave unperformed checks marked Not checked.

## 4. Plan the infographic message and layout

Use the storyboard to organise an evidence-based headline, brief context, the relevant chart or charts, a short explanation, limits and sources. Decide a reading order and suitable canvas dimensions for the intended viewer. The optional 800 × 1200 px layout guide is a starting point; adapt or create your own design. Only write a final headline after the evidence supports it.

Check: A chart can be part of an infographic; there is no mandatory number of panels or charts. Keep the message understandable without spoken commentary and avoid overcrowding.

## 5. Build the infographic with GIMP layers

Create a canvas in GIMP or open the optional OpenRaster .ora layout guide. Check its named layers. The guide contains raster text: hide or replace placeholder layers and create your own editable GIMP text layers. Import verified Excel chart images with Open as Layers, then scale proportionally. Add relevant, credited images/icons where useful and use consistent alignment, spacing, fonts and colours. Keep a visible background suitable for JPEG.

Check: The .ora helper is not a native .xcf or a completed infographic. Its text is not an editable GIMP text object. Check the imported layers in your GIMP edition before relying on the helper.

## 6. Check evidence, citations and readability

Compare every displayed number, unit, denominator and label with the Excel evidence log. Check chart scales, category order, legible text, contrast and reading flow at the intended viewing size. Add traceable data and visual credits and retain licence/permission notes. Identify any AI-generated decorative visuals honestly; the learning images do not establish your results. Remove or hide all template prompts before export.

Check: Citing an image is not permission to reuse it. Use more than colour alone to convey an important distinction. A polished layout does not compensate for an unsupported claim.

## 7. Save XCF, export JPEG and inspect both files

Use File > Save or Save As to save the GIMP working project as .xcf, then File > Export As to export a separate .jpg. Inspect the JPEG preview and choose settings that keep text and charts readable; the task gives no fixed quality number. Reopen the .xcf and check layers, then open the .jpg separately and inspect dimensions, clipping, legibility, credits and placeholder removal. Prepare Task 2.3 in Exam Resolver for English feedback on your evidence notes and selected step, make changes in the actual project and submit your files yourself.

Check: JPEG does not preserve layers or transparency. A file renamed from .png to .jpg is not a JPEG export, and a flattened image renamed .xcf is not an editable GIMP project. Written notes cannot prove these file checks were performed.

## Optional layout guide

Optional six-layer OpenRaster layout guide, 800 × 1200 px. Open it in GIMP, inspect the layers, hide/replace raster placeholder text and create your own GIMP text layers. Add your actual Excel charts and evidence, save the project as .xcf and export a separate .jpg. This download is neither final deliverable. The archive and preview were checked; a GIMP open/save round trip was not tested on this machine.

## Final checks

- Dataset provenance: Kaggle dataset URL, creator, version, original source and reuse terms are recorded.
- Excel profile: Actual row/column counts, row meaning, types, units, missingness and cleaning are documented.
- EDA evidence: Selected findings trace to actual ranges, methods, denominators, filters and checked calculations.
- Visual integrity: Chart type, labels, units, scale and sample are suitable; no invented or unsupported claims.
- Original GIMP design: Own charts and content replace the guide; named layers and editable text are inspected.
- Credits and reading: Data/visual credits, reuse conditions, contrast and readability are checked; prompts removed.
- Two actual files: The .xcf reopens with layers; the separately exported .jpg is readable and matches the project.
