## ARP Task 1.4 Incorporating Visualisations

Task 1.4 has four questions. Q1 inserts the supplied chart at the end of the supplied Word document, changes male users in March to 45892 and female users in December to 91364 in Excel, and observes whether changes appear. A linked chart is the lesson-based Q1 workflow interpretation; the brief itself says insert, not explicitly link. Q2 explicitly embeds the chart at the end, makes the same external Excel edits and records observations. Use independent baseline copies: linked content may refresh from an accessible source, whereas an embedded workbook is a separate editable copy and external workbook edits should not update it. A picture is static, not an embedded chart. Do not claim either experiment has been performed from expected behaviour alone. Q3 requires a separate table with Name, Age, Location and John/30/New York, Alice/25/Los Angeles, Bob/28/Chicago, plus the equations in the original image. The supplied Q3 image contains two equation displays. The first shows a stacked fraction with denominator 3 and 2a following outside the fraction. The second uses inline/slash division by 2a, with unclear grouping. These are not unambiguously the same expression. Reproduce the supplied displays in Equation Editor and confirm unclear grouping with the tutor. Do not silently change the denominator 3 or substitute the conventional quadratic formula with denominator 2a. No values of a, b or c are supplied and no numerical roots are requested. Q4 uses the document created in the preceding activities to generate separate lists of figures, tables and equations. Use matching caption labels and update all three lists. Different numbered source links are provided; do not assume those files are identical or replace them with the lesson's separate Report.docx demonstration. The brief does not specify a report word count, fixed page number, font, screenshot submission or a new PowerPoint. Desktop Office features are needed for the documented native chart embedding/linking workflow; Word for the web does not provide the same embedded-object tools. Confirm desktop access or a tutor-approved alternative. Exam Resolver reviews written plans and check notes in English; it cannot certify native chart relationships, refresh results, equation objects or caption fields from notes or generated images. The learner verifies the saved files and submits them.
