# DVS Module 3 study resources

Course FI1BBDV75. Checked against all forty-one linked content chapters of the signed-in Module 3 book on 14 October 2026, plus its overview.

Four original English lesson explanations cover Lessons 3.1–3.4. Four main tasks have seven-step walkthroughs; twelve Lesson 3.1 research activities and two Lesson 3.4 Excel activities have independent guides and working notes. All eighteen entries are searchable in Exam Resolver. The resolver reviews written reasoning and supplied data; actual native chart formatting and reopen checks must be performed in Excel.

In Learn & Practice, select Data Visualisation, then Course Content and Show lessons from Module 3. Each lesson has a task/activity selector, selected-step instructions, checks, a Markdown working template and a Prepare button. Task 3.1 also offers an editable Word scaffold. All four lessons and the ten reviewed Module 3 quiz questions are also available in Training Center.

## Tasks and source distinctions

- [Task 3.1](https://learning.noroff.no/mod/book/view.php?id=22906&chapterid=81608): a 3–4 page process-focused best-practice document, a proper conclusion and acknowledged sources. The Word template uses placeholders; final pagination must be checked after writing.
- [Task 3.2](https://learning.noroff.no/mod/book/view.php?id=22906&chapterid=81614): L2 bakery line chart, Bakery sales title, primary major vertical gridlines and an outer chart-area shadow.
- [Task 3.3](https://learning.noroff.no/mod/book/view.php?id=22906&chapterid=81620): L3 employees as X and revenue as Y; specified titles, minimum bounds and an exponential trendline.
- [Task 3.4](https://learning.noroff.no/mod/book/view.php?id=22906&chapterid=81627): L4 prices, supplied upper bins and the complete formatting checklist. Source frequencies are 5, 6, 1, 4 and More 0. The supplied unequal numerical widths make a zero-gap frequency-column chart different from an area-faithful histogram.
- [Activities 3.4.1 and 3.4.2](https://learning.noroff.no/mod/book/view.php?id=22906&chapterid=81625): independent toy-product comparisons. The source income figures equal sold items multiplied by production cost; retain the supplied values and clarify their definition rather than silently treating them as profit.

The twelve Lesson 3.1 activities retain their original chapter links. The cutting prompt does not define the term; its research guide distinguishes a sourced definition from an assumed meaning. None of the official task solutions or walkthrough videos was opened to claim a student output was completed.
