# DVS module quiz revision

Course: FI1BBDV75 — Data Visualisation. Reviewed 14 October 2026.

The bank contains 39 distinct English practice adaptations covering all 40 question occurrences in the four reviewed ten-question attempts. Module 2 repeated its bias question at positions 4 and 9; both positions remain in the source metadata. This is a snapshot of observed questions, not the entire randomised Noroff question pool.

Answer concepts were checked against the visible official feedback after submission. Private attempt links, student identifiers and grades are excluded from this bank. Question wording is adapted; for example, asking whether colour alone is sufficient reverses the original negative statement, and the answer is therefore False.

Key distinctions:

- “Weak fidelity” is not the accepted term. The official feedback requires **low fidelity**, so the terminology question is False.
- A trendline can emphasise an observed trend; markers identify individual points.
- Histogram width represents a bin interval. Frequency is the height for equal-width bins; unequal-width bins require frequency density.
- “Line with bars” and “Line column” are not the named subtypes in the course lists. Excel can nevertheless combine chart types or add up/down bars.
- The course contrasts canvas-based storytelling with a traditional slide sequence. Storytelling can also be linear.
- PowerPoint labels depend on platform, release and customisation; recognise the function as well as the course's terminology.

## App access

Learn & Practice → Data Visualisation → Module Quiz Bank. Select a module/question, check your answer, review the English explanation and example, and use the Exam Resolver button to practise your reasoning. Reviewed references also reach the resolver's normal and strict AI context. AI generation requires the app's configured provider; the bank, deterministic answer check, illustrations and notes download work without AI.

The same questions are registered in the existing Practice Questions and Exam Simulator banks. Exam Simulator supports four module source filters and caps the DVS selection at the number of distinct questions to prevent repeats. The separate Training Center lesson quizzes remain as additional lesson practice.
